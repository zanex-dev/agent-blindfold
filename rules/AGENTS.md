# Media Privacy & Anti-Ban Isolation Rule (agent-blindfold v1.1 / Heart-Under-Blade)

- **Default Media Isolation**: When scanning directories, searching files, or reading content outside explicitly exempted engineering scopes, strictly skip local binary image, video, and audio files (`.jpg`, `.jpeg`, `.png`, `.gif`, `.webp`, `.bmp`, `.ico`, `.heic`, `.heif`, `.avif`, `.mp4`, `.mkv`, `.avi`, `.mov`, `.webm`, `.flv`, `.wmv`, `.mp3`, `.wav`, `.flac`, `.m4a`, `.ogg`, `.aac`).
- **Personal & External Vaults Strictly Forbidden**: Never read, inspect, copy, or run scripts on media files located in personal system folders (`Pictures`, `Videos`, `Music`, `AppData`, or root `Desktop`, `Downloads`, `Documents`) or any external directory outside the active project workspace.
- **Engineering Sandboxes & Current-Session Workspace Full Read/Edit Auto-Exemption (Tier 0)**: Plain-text `.svg` vector files inside project workspaces/sandboxes, Antigravity project sandboxes (`~/.gemini/antigravity/scratch/<subproject>`), the current conversation's artifact directory (`brain/<conversation-id>`, including current-session `.user_uploaded` attachments and `scratch/`), and Playwright visual verification screenshots (`<workspace>/.playwright-mcp/`) are automatically exempted for full read, write, generation, and programmatic media editing/processing (e.g., slicing tall screenshots, cropping, resizing, or converting via `PIL`/`Pillow`, `cv2`, `ffmpeg`, ImageMagick, or Canvas scripts). Cross-conversation `.user_uploaded` attachments in other sessions remain strictly off-limits.
- **Session-Start Timed / Permanent Passes (`.allow_media`)**: Dedicated engineering workspaces automatically receive a timed (default `2h` TTL) or permanent `.allow_media` pass at `SessionStart` according to user policy (`~/.gemini/config/agent-blindfold.json`), permitting full reading, generation, and script-based editing/processing of project media assets needed for the current task. If a workspace pass is absent or expired, politely ask the user to grant or renew it via `unlock.ps1` / `unlock.sh` / `blindfold-control.cmd`.
- **Anti-Tamper & No Bypass on Blocked Scopes**: Never create, modify, delete, or forge `.allow_media`, `agent-blindfold.json`, or invoke `unlock.ps1` / `unlock.sh` yourself. If a tool call targeting a private, external, cross-session, or locked path is blocked by `agent-blindfold`, respect the denial immediately and never attempt shell encoding (`base64`, `certutil`, `xxd`), `PIL`/`cv2`, or `ffmpeg` bypasses against that blocked path.
